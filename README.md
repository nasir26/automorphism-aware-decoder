# automorphism-aware-decoder

**Status: Phase 0 (reconnaissance, environment, prior art) done; waiting for approval of the
novelty statement and hypotheses before Phase 1. No results yet.**

Exact symmetry analysis of circuit-level surface code decoding problems, by twin contraction and
nauty (GraphCrunch), and tests of whether that symmetry helps a neural pre-decoder, an FPGA weight
memory, decoder verification and confidence gating.

Author: Nasir Ali, Embedded Systems Division, C-DAC Noida.
